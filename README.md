# Henri Promo

Prototype vidéo 50 secondes, format horizontal 1920×1080 à 30 images/seconde, réalisé avec Remotion.

## Démarrer

Installer Node.js 20+, puis :

```bash
npm install
npm start
```

Pour générer un MP4 :

```bash
npm run render
```

## Étape suivante

Le prototype actuel est une **maquette animée typographique**, sans voix, musique ni captures de l’application. Nous ajouterons les véritables captures de Henri (calendrier, planifications, groupes et évaluations), puis les transitions cinématiques. Le code de l'application originale reste inchangé.
